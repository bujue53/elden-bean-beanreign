ELDEN BEAN: BEANREIGN（黑夜豆临）0.0.1

运行：
将整个 ZIP 解压到任意文件夹，双击 ELDEN BEAN.exe。
请保留同目录下的 resources、locales 和 DLL 等文件，不要只复制 EXE。
Windows 10/11 64 位；需支持 WebGL 2 的显卡及驱动，使用键盘和鼠标。
无需安装 Node.js、Unity 或 Blender；无需联网。

开始游戏：
Enter 开始，方向键选择职业、Enter 确认，然后点击画面进入战斗。
关闭窗口即可退出。F11 或 Alt+Enter 切换全屏。

操作：
W/A/S/D 移动；鼠标调整视角；E 或鼠标中键锁定 BOSS。
左键普攻；按住右键蓄力，松开释放。
隐士的普攻和蓄力攻击均为远程法术。
轻点 Shift 翻滚；移动并按住 Shift 冲刺；空格跳跃。
R 喝药，每次挑战四瓶；死亡后 R 复活，保留 BOSS 剩余血量。
BOSS 破韧失衡后，靠近正面并面对 BOSS，左键处决。
处决动作包含刺入、停顿、缓慢拔出；BOSS 全程固定，结算两段伤害。
Esc 暂停；菜单可继续、重新挑战或返回标题。切换窗口会自动暂停。

这是非官方同人学习作品，包含参考原作形象重建的轻量风格化模型。
本包未作商业代码签名。游戏无存档，退出或重开会清除本局进度。
