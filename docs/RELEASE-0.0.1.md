# ELDEN BEAN: BEANREIGN 0.0.1

首个 Windows 便携版。下载 **ELDEN-BEAN-BEANREIGN-0.0.1-win-x64.zip**，完整解压后双击 **ELDEN BEAN.exe**，即可在独立窗口中离线游玩。无需安装 Node.js、Unity 或 Blender。

## 本版内容

- 四个 Blender 人形职业与参考原作布德奇冥形象制作的 BOSS。
- R 喝药；隐士普通攻击、蓄力攻击均为远程法术。
- 近身正面处决：刺入、停顿、缓慢拔出，期间 BOSS 固定，结算两段伤害。
- F11 或 Alt+Enter 切换全屏，Esc 暂停，关闭窗口退出。

## 下载与游玩

1. 下载下方的 **win-x64.zip**，不是 GitHub 自动生成的 Source code 压缩包。
2. 选择“全部解压”，保留文件夹内全部文件。
3. 双击 **ELDEN BEAN.exe**。Enter 开始，选择职业后点击画面进入战斗。

Windows 10/11 64 位；支持 WebGL 2 的显卡及驱动；键盘和鼠标。完整按键见压缩包内的 **游玩说明.txt**。

便携版包含 Chromium 运行环境，因此体积大于网页源码。本版没有商业代码签名；无存档、探索关卡、多人联机或手柄支持。
